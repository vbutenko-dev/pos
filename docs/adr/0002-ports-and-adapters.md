# ADR-0002. Граница между сценариями и адаптерами

Дата — 23 ноября 2026 года. Статус — принято.

## Контекст

Преподаватель работает через меню. Те же операции нужны для восстановления оценок из файла и проверки предметных правил в тестах.

## Решение

В архитектуре Ports and Adapters фасад Gradebook предоставляет сценарии выставления, исправления и отмены оценки. Порт Repository объявлен в пакете application. Адаптер memory реализует его для текущего сеанса. [Реализация](../../internal/application/gradebook.go)

## Альтернативы

Объединение консоли и ведомости в одном типе связало бы восстановление данных и проверки предметных правил с вводом из терминала.

## Последствия

Консоль передаёт разобранные значения сценарию. Ведомость проверяет регистрацию студента, рубрикатор проверяет балл, а хранилище записывает результат.
