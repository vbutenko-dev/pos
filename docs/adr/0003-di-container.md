# ADR-0003. Сборка зависимостей через dig

Дата — 23 ноября 2026 года. Статус — принято.

## Контекст

Задание требует DI-контейнер. Конструктору Gradebook нужны хранилище и рубрикатор одного курса.

## Решение

Точка входа регистрирует memory.New как реализацию application.Repository через dig.As, затем регистрирует создание рубрикатора и конструктор ведомости. Вызов Invoke получает собранную ведомость и запускает сеанс. [Реализация](../../cmd/pos/main.go)

## Альтернативы

Ручная сборка через NewGradebook подходит для модульных тестов. Для точки входа выбран контейнер в соответствии с условием задания.

## Последствия

Тесты могут передать зависимости напрямую. Ошибка регистрации или сборки возвращается в main до начала работы с ведомостью.
