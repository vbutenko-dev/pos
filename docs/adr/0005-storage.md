# ADR-0005. Хранение ведомости и экспорт итогов

Дата — 23 ноября 2026 года. Статус — принято.

## Контекст

При следующем запуске преподавателю нужны студенты, критерии и исходные баллы. Для передачи результатов достаточно таблицы с итоговыми процентами.

## Решение

В течение сеанса данные хранятся в памяти. При выходе изменённая ведомость записывается в gradebook.json. Экспорт по команде 10 создаёт totals.csv с одной строкой на студента. [Реализация](../../internal/files/json.go)

## Альтернативы

Хранение только CSV с итогами не позволяет восстановить исходные баллы. Для локальной ведомости одного курса достаточно файлов и стандартной библиотеки Go.

## Последствия

Сохранение сравнивает текущий JSON с версией при открытии. При конфликте файл сохраняет внешние изменения. Выгрузку CSV можно повторить после исправления оценки.
