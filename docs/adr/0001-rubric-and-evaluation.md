# ADR-0001. Рубрикатор проверяет балл

Дата — 23 ноября 2026 года. Статус — принято.

## Контекст

Две работы могут иметь разные максимумы. При создании и исправлении оценки действуют одни и те же границы.

## Решение

Рубрикатор хранит критерии по названию. Фабрика Rubric.NewEvaluation связывает ID студента и название критерия с баллом. При создании она вызывает Rubric.CorrectScore, который принимает целое значение от нуля до максимума включительно. [Реализация](../../internal/domain/rubric.go)

## Альтернативы

Проверка диапазона в меню потребовала бы повторять её при загрузке JSON.

## Последствия

Балл 0 допустим. Для лабораторной с максимумом 10 попытка записать 12 возвращает ошибку до изменения записи.
